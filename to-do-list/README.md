# To-Do List

## Sobre o projeto
Uma aplicação web simples e funcional para o gerenciamento de tarefas diárias. O objetivo é oferecer uma ferramenta leve onde o usuário possa registrar suas atividades, definir prazos e acompanhar o que já foi concluído, auxiliando na organização pessoal.

## Funcionalidades
- Adição de tarefas com título, descrição e data de prazo.
- Validação de campos obrigatórios e regras de negócio (descrição com mais de 3 caracteres).
- Marcação de tarefas como concluídas (riscando o texto).
- Remoção de tarefas da lista.
- Contador dinâmico do número de tarefas ativas.

## Tecnologias utilizadas
- HTML5
- JavaScript (Vanilla)

## Estrutura do projeto
- `index.html`: Arquivo único que contém a estrutura HTML, a estilização CSS (inline) e toda a lógica JavaScript.

## Como executar
1. Clone o repositório.
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` em qualquer navegador web moderno.
4. Nenhuma instalação ou servidor é necessário.
