# Portfólio de Desenvolvimento de Sistemas

## Sobre o projeto
Este repositório reúne uma coleção de projetos práticos desenvolvidos durante o curso técnico de Desenvolvimento de Sistemas. O objetivo é aplicar conceitos de lógica de programação, desenvolvimento web (front-end e back-end), banco de dados e organização de código.

## Funcionalidades
- **Sistema de Carrinho de Compras:** Filtragem de produtos, adição/remoção de itens e cálculo de total.
- **Sistema de Análise Estatística:** Cadastro de alunos, cálculo de médias, situação (aprovado/reprovado) e geração de relatórios.
- **To-Do List:** Criação, conclusão e remoção de tarefas com prazo.
- **Primeira Atividade:** Página pessoal de apresentação e portfólio.
- **crud-mundo:** CRUD para gerenciamento de países.

## Tecnologias utilizadas
- HTML5
- CSS3 (e Bootstrap 5)
- JavaScript (Vanilla)
- PHP
- Git e GitHub

## Estrutura do projeto
- `/Primeira Atividade`: Página web pessoal.
- `/Sistema de Carrinho de Compras`: Aplicação web de e-commerce (Front-end).
- `/Sistema Web de Análise Estatística de Turma Escolar`: Aplicação PHP para cálculos escolares.
- `/TO-DO LIST`: Aplicação web de lista de tarefas.

## Como executar
1. Clone o repositório.
2. Abra os arquivos `index.html` diretamente no navegador para as aplicações em JavaScript.
3. Para o sistema em PHP, é necessário um servidor local (como XAMPP ou similar) configurado na pasta do projeto.
