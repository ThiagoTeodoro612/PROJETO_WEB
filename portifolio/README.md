# Primeira Atividade - Página Pessoal

## Sobre o projeto
Este projeto consiste em uma página web pessoal desenvolvida para apresentar um perfil profissional e acadêmico. O objetivo é centralizar informações sobre a trajetória, interesses e projetos desenvolvidos, servindo como um portfólio online inicial.

## Funcionalidades
- Exibição de informações pessoais e trajetória acadêmica.
- Seção de interesses (Desenhos, Desenvolvimento de Jogos, RPG de Mesa).
- Listagem de projetos acadêmicos e pessoais com imagens.
- Navegação interna por âncoras.

## Tecnologias utilizadas
- HTML5

## Estrutura do projeto
- `index.html`: Arquivo principal contendo a estrutura e o conteúdo da página.
- `imgs/`: Pasta contendo as imagens utilizadas na página (fotos, logos e artes).

## Como executar
1. Clone o repositório.
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` em qualquer navegador web moderno.
