# CRUD Mundo - Sistema de Gerenciamento Geográfico

## Informações do Projeto
- **Aluno:** Thiago Gouveia Faria Teodoro
- **Projeto:** CRUD Mundo
- **Disciplina:** Programação Web

## Tecnologias Utilizadas
- **Front-end:** HTML, CSS, Bootstrap, JavaScript, Font Awesome, SweetAlert2, jQuery
- **Back-end:** PHP
- **Banco de Dados:** MySQL
- **Versionamento:** Git e GitHub

## Descrição do Projeto
Sistema completo de gerenciamento de informações geográficas que permite o cadastro, consulta, edição e exclusão de:
- Países
- Cidades
- Continentes
- Governantes

### Funcionalidades Principais
1. **CRUD completo** para todas as entidades
2. **Pesquisa dinâmica** para todas as entidades
3. **Validação de formulários** com JavaScript
4. **Confirmação de exclusão** com SweetAlert2
5. **Design responsivo** com Bootstrap
6. **Estatísticas** em tempo real
